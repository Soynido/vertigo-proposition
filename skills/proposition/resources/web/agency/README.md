# Habillage VERTIGO, pas identité du prospect

Le manifeste versionne les ressources observées sur le site de l'agence. Le logotype est une image retina du wordmark actuel, Didot Regular400, avec son espacement mesuré dans le navigateur. La transcription en contours a été écartée pour ses déliés trop fins. Aucune police propriétaire n'est redistribuée. Les fichiers Poppins portent leur licence SIL OFL jointe. Ne pas fabriquer une variante700 du logo.

`agency.css` est limité à `[data-vertigo-agency]`. Il donne fond blanc, logotype, typographie, espacements et navigation de progression. Il ne choisit ni concept, ni palette, ni mise en page, ni nombre de scènes du prospect. Appliquer les classes au cadre commercial uniquement ; conserver les styles du client dans sa démonstration.

Copier seulement les ressources utilisées dans la liste publique du build, avec leur provenance. Le manifeste conserve les SHA256. Pour la navigation, construire les liens depuis les sections réellement présentes ; l'agent règle `aria-current` depuis la progression effective, conserve le clavier natif et respecte le mouvement réduit. Aucun nombre de chapitres n'est imposé.

Le poster studio est une image fixe de la référence agence. Il n'atteste ni lecture vidéo ni réalisation pour le prospect. Les liens studio servent à identifier une approche existante ; ils ne sont ni des sources de faits sur le prospect ni une direction créative à reproduire. Si un film portfolio est utilisé, le récupérer, vérifier son décodage et ses droits propres, puis le déclarer comme studio dans le plan. Les propres scènes du prospect peuvent démontrer l'approche sans portfolio indispensable.

Le contact public observé est consigné dans le manifeste. Ne jamais inventer le contact du prospect ou transformer le nom du responsable privé en coordonnées publiables.
