# Revue : une matrice canonique

Lire [la matrice et les règles de qualité du principal](../../proposition/references/quality.md). Cette source unique définit les critères 0/1/2, les seuils, les revues isolées, les contrôles finaux et les limites ; ne pas maintenir une copie locale concurrente.

Pour une revue créative, examiner le [contrat créatif exact](../../proposition-creative/references/creative-contract.md), sa tâche de lancement, le brief transmis et les artefacts. Vérifier le lien observations/recommandations → scènes, les signes préservés et la chronologie rendus → inspection → comparaison. Une direction déjà choisie se juge sur les prolongements demandés, sans exiger une alternative.

Pour les rapports d'étape, lire [les cinq critères du passage](../../proposition/references/stage-quality.md) et [ses preuves d'acceptation](../../proposition/references/acceptance.md). Les identifiants et ancrages embarqués du principal font autorité. Les exports PPTX et le contexte suivent [leur contrat de livraison](../../proposition/references/editable-delivery.md).

Rendre les observations, fichiers/empreintes, notes, obligations, défauts et limites sur la même révision. Une procédure suivie, un export mécanique ou une présence de fichier ne certifient pas la qualité esthétique, l'édition dans une application ou le droit de diffusion.
